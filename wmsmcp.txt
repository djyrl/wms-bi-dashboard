# 🔵 库管员 (storekeeper-mcp) — 入库收货上架赋码、出库拣货复核、移库执行、库存查询、RFID补换签
# 🟢 质检员 (inspector-mcp) — 采购入库质检（需求部门/主管部门）
# 🟡 审核人 (approver-mcp) — 库存调整单初审/二审、采购退货审核
# 🟣 计划员 (planner-mcp) — 盘点计划/策略/任务/结果、移库管理、采购订单、领料单
# 🟠 设备管理员 (device-admin-mcp) — 设备管理、RFID标签、机器人、智能货柜、传感器、称重
# ⚪ 仓库管理员 (warehouse-admin-mcp) — 仓库/工厂/站点/库区/货架/货位、库管员分配规则
# 🔴 系统管理员 (system-admin-mcp) — 用户/角色/权限/菜单、KV配置、数据字典、S3、App版本
# 🟤 ERP集成 (erp-integration-mcp) — 所有ERP导入、ERP协作任务、ERP库存快照差异、ERP物料凭证
# ⚫ 报表与分析 (analytics-mcp) — 报表中心、大屏数据、追溯查询、数字孪生
# ⬜ 开放API (open-api-mcp) — 所有 /api/open/** 接口，供外部系统调用
