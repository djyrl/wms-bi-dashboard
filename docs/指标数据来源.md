| `wms_project_inventory` | 项目库存台账 | `owner_project_code` 项目编码、`owner_project_type` 项目类型、`current_quantity`、`locked_quantity` 锁定、`available_quantity` 可用 |
| `wms_material` | 物料主数据 | `code`、`name` 名称、`unit` 单位、`material_group_code` 物料组 |
| `wms_material_group` | 物料组（类别） | `code`、`name` |

| `erp_catalog_mb51` | ERP 物料凭证（全历史） | `bwart` 移动类型(101收货/102冲销/201/221/222/Z61/Z62出库)、`row_json`→`DMBTR` 金额、`MENGE` 数量、`MATNR` 物料、`BLDAT` 凭证日期、`werks` 工厂(=2635)、`charg` 批次 |
| `wbs_zmmrp226_parsed` | ERP 项目/WBS 维度 | `z_dxxmh` WBS码、`post1` 项目描述、`z_name` 提报人、`contact` 联系人、`reqptmt_name` 部门 |
| `wbs_zmmrp048_parsed` | ERP 项目/采购员维度 | `posid`、`zpost1`、`z_user` 采购员 |

### 2. 维度缓存表（物化，由 `fn_refresh_dim_caches()` 刷新）

| 物化表 | 内容 | 主键 |
|---|---|---|
| `dim_material_cache` | 物料维度 | material_code |
| `dim_project_cache` | 项目维度（项目名 / 采购员 `purchaser_name` / 提报人 `project_submitter` / 联系人 `project_contact`） | project_code |
| `dim_location_cache` | 货位维度 | inventory_id |
| `dim_outbound_log_cache` | 出库日志维度（total_outbound_quantity、pick/repair/scrap/repaired 分项数量、`last_outbound_time` 最后出库时间） | tenant_id + material_code + batch_code + erp_inventory |

### 3. 核心视图 / 中间层

- **`v_project_inventory_wide`（核心宽表）** — 以 `wms_inventory` 按批次聚合（`inv_agg`），再 LEFT JOIN `wms_project_inventory`、`dim_material_cache`、`dim_project_cache`、`dim_outbound_log_cache`。
  - ⚠️ **行数 = 批次 × 项目（会膨胀）**，聚合金额前必须先按物理批次去重。
- **`v_batch_lifecycle`** — 批次生命周期（ERP 账面余额 + WMS 实物库存，来自 `sql/04_erp_inventory_views.sql`）。
- `v_monthly_inventory_timeline` / `v_material_monthly_inventory` — ERP 月度库存时序（本页未直接用到）。

### 4. 统一金额口径（`utils.py` 的三个核心金额）

| 金额 | 公式 | 含义 |
|---|---|---|
| 入库金额 `inbound_amount` | `original_quantity × unit_price` | 以当前加权均价重估原始入库量 |
| 领用金额 `claimed_amount` | `total_outbound_quantity × unit_price` | 以当前加权均价重估累计出库量（**非历史真实出库价**） |
| 库存金额 `inventory_amount` | `total_price = Σ(current_quantity × unit_price)` | 当前库存真实价值 |
| 加权均价 `unit_price` | `Σ(qty×price)/Σqty`（qty>0 时，否则 `MAX(unit_price)`） | — |
| 库龄 `age_days` | `CURRENT_DATE - COALESCE(inbound_date, create_date)` | 在视图里已算好 |
| 项目分配 `project_ratio` | 批次内按各项目 `pi_current_quantity` 占比 | 同批次 Σratio = 1 |

**恒等式：`入库 ≈ 领用 + 库存`**（前提 `original_quantity ≈ current_quantity + total_outbound_quantity`）。

## 二、指标清单

### 页面 A — AnalysisHub（分析中心）

#### 顶部 KPI（4 个）

| 指标 | API → 后端函数 | 数据来源表/视图 | 计算过程 |
|---|---|---|---|
| A1 当前库存总额 | `getWmsSummary()` → `summary.py:get_summary()` | `v_project_inventory_wide`（`_get_batch_rows()` 物理批次去重） | `Σ total_price = Σ Σ(current_quantity × unit_price)`，元→万元 |
| A2 采购领用率（当年） | `getErpClaim()` → `erp_inventory.py:get_erp_claim_indicators()` | **`erp_catalog_mb51`**（非 WMS） | 当年出库金额 / 当年净入库 × 100%；出库=`bwart IN (201,221,222,Z61,Z62)` 的 `-(DMBTR)` 求和；净入库=`bwart IN (101,102)` 的 `DMBTR` 求和；当年=`BLDAT` 前 4 位=当前年 |
| A3 入库总额（当年） | 同 A2 | `erp_catalog_mb51` | `Σ DMBTR WHERE bwart='101'`（收货），当年 |
| A4 加权平均库龄 | `getTimeIndicators()` → `time_indicators.py:get_time_indicators()` | `v_project_inventory_wide`（`_get_batch_rows()`） | `Σ(库存金额 × 库龄天数) / Σ(库存金额)`；副标题 `≥1年占比 = 库龄≥365天的库存金额/总库存` |

#### 快速一览（6 个卡片）

| 指标 | API → 后端函数 | 数据来源 | 计算过程 |
|---|---|---|---|
| A5 TOP 8 项目库存占比 | `getStructure()` → `structure_indicators.py:get_structure_indicators()` 的 `project_ratios` | `v_project_inventory_wide`（批次去重 × project_ratio） | `Σ(批次库存金额 × project_ratio)` 按 `owner_project_code` 聚合，`占比 = 项目库存/总库存` |
| A6 未领用库存 TOP 8 | `getTopUnclaimedAmount(8)` → `top_indicators.py:get_top_unclaimed_amount()` | `v_project_inventory_wide`（`_get_inventory_rows()` 项目级明细） | 按 `inventory_amount`（项目分配后）降序取前 8 |

| A10 智能库存优化建议 TOP 5 | `getOptimizeSuggest(5,60)` → `top_indicators.py:get_optimize_suggest()` | `v_project_inventory_wide`（`_get_inventory_rows()`） | 按物料聚合 → `日均消耗 = 已领用金额 / 加权平均库龄`；`建议上限 = 日均消耗 × 60天`；保留「当前库存 > 建议上限」的物料 |

## 三、⚠️ 重要口径差异

1. **「采购人/负责人」字段在三个接口含义不同**：
   - `getStructure().purchaser_ratios`（A8、B11）→ `purchaser_name` = `dim_project_cache.purchaser_name` = ERP `z_user`（采购员）
   - `getByPurchaser()` / K9 → `project_contact`（联系人）
   - `_get_inventory_rows()` 输出里的 `purchaser_name`（被 T1/未领用 TOP 使用）→ `project_submitter`（提报人）

2. **「所有库存金额」（B5）是 ERP 口径**（`v_batch_lifecycle` 的 `best_inventory_amt`），与其它「当前库存」的 WMS 口径（`v_project_inventory_wide`）不一致，二者相差约「ERP有余额_WMS无」批次的金额。

3. **K1 / K4 显示 ERP 数字，但 K3 / K5–K9 / T1–T2 是 WMS 数字**——考核清单内部存在两套数据源混用。

4. **领用金额是「重估」而非历史真实价**：`total_outbound_quantity × 当前加权均价`，不是出库当时的实际金额（`wms_inventory_log` 无价格字段）。
